# 🎵 AuraWave 線上音樂播放器 (Online Music Player)

> 🌐 **線上公開體驗網址**：[https://stteach01-jpg.github.io/music-player/](https://stteach01-jpg.github.io/music-player/)  
> 📦 **GitHub 儲存庫**：[https://github.com/stteach01-jpg/music-player](https://github.com/stteach01-jpg/music-player)

這是一個現代化、即開即用、無須安裝任何依賴的 Web 線上音樂播放器。支援手機與電腦瀏覽器，開啟網址即可隨處使用。

## ✨ 功能特色

1. **音檔支援與上傳**：
   - 支援檔案選取器上傳或直接**拖曳檔案**進視窗（支援 MP3、WAV、FLAC、OGG、M4A 等音訊格式）。
   - 內建**「範例示範曲」**（透過 Web Audio API 自動合成），點擊即可立即試聽與體驗動態效果，無須事先準備音檔。
2. **完整播放控制**：
   - **播放 / 暫停**（圖示即時切換）
   - **快進 10 秒 / 倒退 10 秒**
   - **停止播放**（立即暫停並重置回 00:00）
   - **單曲循環切換**、**播放倍速切換**（0.75x ~ 2.0x）
   - **即時進度條拖曳 / 點擊跳轉**（顯示目前時間與總時長）
3. **音量與音效平衡控制**：
   - 精確百分比音量滑桿（0% ~ 100%）。
   - 一鍵靜音與音量記憶恢復，圖示隨音量大小動態切換。
   - **音效音量平衡（Loudness Normalizer）**：
     - 利用 Web Audio API 的 `DynamicsCompressorNode` 自動平準化音量，防止忽大忽小與爆音，讓不同音樂的音量維持平順一致。
     - **左右聲道平衡（Stereo Balance）**：支援 L/R 聲道平移微調。
     - **EQ 音場預設風格**：標準平衡、人聲突出、低音增強、深夜柔和。
4. **動態同步歌詞與顯示/隱藏**：
   - **一鍵隱藏/顯示歌詞**：點擊上方「隱藏歌詞」或按快捷鍵 `L`，播放器會自動優雅收合歌詞並居中聚焦黑膠轉盤，再次點擊即可展開。
   - 支援標準 `.lrc` 時間軸格式（如 `[00:15.30]歌詞內容`）。
   - 當前播放行**自動高亮、放大並平滑居中滾動**。
   - 支援**點擊任意歌詞行直接跳轉**至該時間點播放。
   - 提供「匯入歌詞」上傳檔案及「編輯/貼上」彈跳視窗隨時貼上歌詞。
5. **視覺氛圍與音訊視覺化**：
   - 擬真黑膠唱盤隨音樂播放自動旋轉。
   - 結合 Web Audio API 的**即時音訊頻譜律動條 (Realtime Audio Visualizer)**。
   - 科技深色玻璃擬態 (Glassmorphism) 設計風格。
6. **鍵盤快捷鍵**：
   - `空白鍵 (Space)`：播放 / 暫停
   - `←` / `→`：倒退 / 前進 10 秒
   - `↑` / `↓`：調整音量
   - `S`：停止播放
   - `M`：靜音開關
   - `L`：隱藏 / 顯示歌詞面板
   - `B`：開啟 / 關閉音效音量平衡

可以直接在瀏覽器中開啟：
- 檔案位置：[index.html](file:///g:/我的雲端硬碟/2026_Antigravity2/music-player/index.html)
